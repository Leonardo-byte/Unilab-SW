# UniLab Frontend - Microservicio

Plataforma de pruebas inteligentes para el ADCS basada en una jaula de Helmholtz Y un simulador solar

Para ejecutar el fronted via web
ejecutar los siguientes comandos

dirigirse a la ruta de la carpeta 

```
cd tu_carpeta/Platf-ADCS/
```

Luego ejecutar los siguientes comandos

```
npm install
```
y

```
npm run dev
```

Se mostrare un url: http://localhost:5173/


Requisitos: Tener instalado Node.js
